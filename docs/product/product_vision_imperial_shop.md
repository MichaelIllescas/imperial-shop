# Product Vision - Imperial Shop 

## Visión del producto

Desarrollar una plataforma de comercio electrónico modular, reutilizable
y lista para personalización, que permita implementar rápidamente
tiendas online completas para distintos clientes, reduciendo tiempos de
desarrollo, costos y complejidad técnica.

## Público objetivo

Clientes futuros de Imperial Net que necesiten: - Tiendas online -
Sistemas de ventas digitales - Integración con pagos y envíos

## Problema que resuelve

Evita la necesidad de desarrollar desde cero cada tienda online,
reduciendo tiempo, costos y duplicación de esfuerzo en integraciones.

## Propuesta de valor

-   Implementación rápida
-   Integraciones listas (Mercado Pago + Correo Argentino)
-   Arquitectura escalable
-   Base adaptable
-   Reducción de costos

## Alcance del producto

### Front público

-   Catálogo de productos
-   Búsqueda y filtros
-   Carrito de compras
-   Checkout con Mercado Pago
-   Selección de envío
-   Historial de pedidos

### Panel de administración

-   Gestión de productos
-   Gestión de stock
-   Gestión de clientes
-   Gestión de usuarios
-   Gestión de pedidos
-   Gestión de envíos
-   Reportes básicos

## Arquitectura técnica

-   Frontend: Angular 21 + Tailwind
-   Backend: Java 21 + Spring Boot 4
-   Base de datos: MySQL
-   Integraciones: Mercado Pago y Correo Argentino

## Metodología

-   Scrum
-   Git Flow
-   Jira

## MVP

-   CRUD de productos
-   Carrito
-   Checkout con Mercado Pago
-   Gestión de pedidos
-   Panel admin básico
-   Stock simple

## Principios

-   Reutilizable
-   Modular
-   Escalable
-   Configurable
