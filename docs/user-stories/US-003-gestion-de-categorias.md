# US-003 - Gestion de categorias

## Historia

Como administrador de tienda,
quiero crear y administrar categorias,
para organizar el catalogo y mejorar la navegacion de productos.

## Valor de negocio

Permite estructurar el catalogo y preparar la tienda para publicar productos.

## Criterios de aceptacion

- [ ] El admin puede crear categorias.
- [ ] El admin puede editar nombre y estado de una categoria.
- [ ] El admin puede activar/desactivar categorias.
- [ ] El sistema valida nombre obligatorio y unicidad basica.

## Reglas de negocio

- Solo admin puede gestionar categorias.
- Categoria desactivada no debe aparecer en navegacion publica.

## Dependencias

- Login admin y control de permisos.
