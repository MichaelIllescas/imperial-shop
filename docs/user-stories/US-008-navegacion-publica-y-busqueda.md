# US-008 - Navegacion publica y busqueda

## Historia

Como visitante,
quiero navegar categorias y buscar productos,
para encontrar rapidamente lo que deseo comprar.

## Valor de negocio

Aumenta descubrimiento de productos y mejora conversion de la tienda.

## Criterios de aceptacion

- [ ] El visitante puede navegar categorias activas.
- [ ] El visitante puede buscar productos por texto.
- [ ] El visitante puede aplicar filtros basicos (categoria, rango de precio, disponibilidad).
- [ ] El sistema muestra solo productos publicados en resultados.
- [ ] Si no hay resultados, el sistema muestra mensaje claro y sugerencias.

## Reglas de negocio

- Productos no publicados no deben aparecer en busqueda ni navegacion.
- Filtros aplican sobre catalogo publico vigente.

## Dependencias

- Gestion de categorias y productos publicada.
