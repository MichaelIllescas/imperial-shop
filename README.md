# Imperial Shop

Plataforma de comercio electronico modular y reutilizable, pensada para acelerar la implementacion de tiendas online personalizables para distintos clientes.

## Vision del producto

Imperial Shop busca evitar el desarrollo desde cero en cada proyecto e-commerce, reduciendo tiempos, costos y complejidad tecnica mediante una base escalable y adaptable.

## Publico objetivo

Clientes de Imperial Net que necesitan:

- Tiendas online
- Sistemas de ventas digitales
- Integracion con pagos y envios

## Problema que resuelve

- Elimina la duplicacion de esfuerzo entre proyectos
- Reduce tiempos de salida al mercado
- Simplifica integraciones clave de negocio

## Propuesta de valor

- Implementacion rapida
- Integraciones listas (Mercado Pago + Correo Argentino)
- Arquitectura escalable
- Base adaptable para personalizaciones
- Reduccion de costos de desarrollo

## Alcance funcional

### Front publico

- Catalogo de productos
- Busqueda y filtros
- Carrito de compras
- Checkout con Mercado Pago
- Seleccion de envio
- Historial de pedidos

### Panel de administracion

- Gestion de productos
- Gestion de stock
- Gestion de clientes
- Gestion de usuarios
- Gestion de pedidos
- Gestion de envios
- Reportes basicos

## Arquitectura tecnica

- Frontend: Angular 21 + Tailwind
- Backend: Java 21 + Spring Boot 4
- Base de datos: MySQL
- Integraciones: Mercado Pago y Correo Argentino
